🚀 Cómo desplegarlo gratis

Opción 1 — GitHub Pages (recomendado):
1. Crea un repositorio privado en github.com
2. Sube este archivo como index.html
3. Settings → Pages → Deploy from branch
4. Accedes desde cualquier dispositivo con tu cuenta GitHub

Opción 2 — Netlify Drop:
Ve a app.netlify.com/drop y arrastra este archivo. En 30 segundos tienes una URL.

Seguridad: Todos los datos se guardan cifrados (AES-256) en el localStorage de tu navegador. Ningún servidor externo tiene acceso a tus claves. El cifrado ocurre 100% en tu dispositivo.
